Power Link

BETA TESTING

A generic cause-and-effect utility, not a full objective on its own - a building block Zeus can use to wire real consequences into a mission. Destroy the source, the target reacts.

  1. Zeus places one Power Link module and syncs it to a source (a generator, comms relay - anything destructible) and a target (a rayshield or container).
  2. Multiple sources can be synced, with a toggle for whether any one or all of them need to be destroyed.
  3. Once the condition is met, rayshields are removed and containers unlock - fires once, permanently.

Note — stack several Power Links together to build a whole base out of simple pieces - e.g. one generator feeding both a shield and a comms tower that calls in reinforcements if left standing.
