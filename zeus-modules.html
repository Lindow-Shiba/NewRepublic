Zeus Modules Reference

Every Zeus module this mod adds, all placed under the New Republic category in Zeus. None of the vehicles or gear add Zeus modules - it's all objective/utility tools. Full setup steps live on each tool's own page; this is the quick-reference version.

Cipher Terminal RELEASE

Cipher Terminal LockSync to a terminal prop plus one or more targets (containers/rayshields). Pick a cipher system; players decode it by hand at the terminal.

Signal Relay Chain BETA

Signal Relay ChainSync to relay props in activation order. Only the current relay is lit; players hold position near it to advance the chain.

Power Link BETA

Power LinkSync a destructible source (or several) to a target (rayshield/container). Toggle whether ANY or ALL sources must be destroyed to trigger it.

Access Point BETA

Access PointSync a keypad object plus a target. Set a silent disable time and (optionally) a required role keyword - or leave it open to anyone. Destroying the keypad works too, just marks it as breached instead of quiet.

Note — every module here reads its synced objects automatically - Zeus doesn't need to configure which synced object is which, just sync the right pieces and place the module.
